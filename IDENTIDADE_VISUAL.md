# Identidade Visual — MindFlow

Este documento serve como referência de estilo para toda a interface e páginas do MindFlow, incluindo a landing page.

## Modo

Dark mode fixo (sem toggle por enquanto).

## Paleta de cores

| Uso | Cor | Hex |
|---|---|---|
| Fundo principal | Preto quase puro | `#0a0a0d` |
| Fundo de cards/superfícies | Cinza muito escuro | `#14141a` |
| Cor primária (roxo/violeta) | Violeta | `#7c5cfc` |
| Cor de destaque (ciano) | Ciano | `#2dd4d4` |
| Cor de sucesso (verde) | Verde | `#4ade80` |
| Cor de alerta/streak (âmbar) | Âmbar | `#fbbf24` |
| Cor de conquista (rosa) | Rosa | `#ec4899` |
| Texto principal | Branco | `#ffffff` |
| Texto secundário | Cinza claro | `#9ca3af` |
| Bordas | Cinza escuro, baixo contraste | `#2a2a35` |

## Tipografia

- Fonte sans-serif moderna (ex: Inter, `system-ui` como fallback).
- Títulos: bold, alto contraste (texto principal sobre fundo escuro).
- Texto secundário: peso regular, cor mais suave (`#9ca3af`).

## Estilo de componentes

- Cantos arredondados (border-radius médio, ~8-12px).
- Cards com fundo levemente mais claro que o fundo da página (`#14141a` sobre `#0a0a0d`).
- Espaçamento generoso, respiro visual.
- Sem sombras pesadas — o contraste vem da cor de fundo dos cards, não de elevação artificial.

## Logo

Símbolo de infinito (∞) em roxo com contorno, atravessado por um raio em ciano no centro — representa fluxo contínuo + energia/ação. Fundo preto, cantos arredondados quando em formato de ícone quadrado.
